# Memulai Business Flow

Panduan lengkap (19 langkah, FAQ, glosarium, pemecahan masalah) tersedia di aplikasi: halaman publik `/guide` dan menu **Pusat Bantuan**. Isinya bersumber dari `src/components/guide.tsx` dan hanya menjelaskan fitur yang tersedia.

Ringkas:
1. Buka website → **Mulai Siapkan Bisnis**.
2. Jawab kebutuhan, pilih jenis usaha, isi nama bisnis → buat PIN 4–6 angka.
3. Lengkapi profil, wilayah, akun kas/bank, cabang, modul, mode tampilan → setujui Syarat & Privasi.
4. **Buka Dashboard Bisnis** (perangkat ini menjadi Owner Device). Masukkan PIN.
5. Tambah perangkat lain: Perangkat & Keamanan → kode pairing → di perangkat baru pilih **Sambungkan Perangkat**.
6. Lupa PIN: layar PIN → **Ubah PIN** (kanan bawah). Perangkat hilang: cabut dari Perangkat & Keamanan.
